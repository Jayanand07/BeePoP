# 🍯 Beepop — Pure As Nature

**Beepop** is a premium single-serve pure honey brand from Kolkata, India.

Each Beepop stick is a tear-open sachet of 100% pure, single-origin honey — no added sugar, no additives, no mess. Just real honey from the apiaries of Bengal, ready to go wherever you do.

### Why Beepop?
- 🐝 100% pure & natural — cold-extracted, never pasteurised
- ✋ Tear-and-go — no spoon, no jar, no sticky fingers
- 🌿 Single-origin honey from Bengal
- ✈️ Travel-friendly, pocket-sized, mess-free
